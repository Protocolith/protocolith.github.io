Protocolith

Records, verifies and issues trial records.

Freeze the protocol before the run. Record every result in a hash-chained ledger. Verify that the history still adds up. Issue an evidence card. Python, standard library only; a command line, a Python API and an MCP server for AI agents.

DocumentationGitHubPyPIDOI

1. Freeze

The protocol and its SHA-256 are stored before anything runs, so thresholds cannot move after you see the result.

2. Record

Every run goes in, including failed and blocked ones. A closed status vocabulary keeps "no data" from turning into "negative".

3. Verify and anchor

Any silent edit breaks the hash chain. Anchoring the head outside the ledger (RFC 3161 time-stamp, git tag, Wayback Machine, Zenodo) detects even a full rewrite or a cut-off ledger.

Try it

pipx install protocolith
protocolith init
protocolith freeze protocol.json
protocolith record record.json
protocolith verify-ledger
protocolith summary

For AI agents

The MCP server (protocolith mcp) exposes tools to freeze, record, verify, summarize and issue records and to read the specification and schemas. It also offers a claim check (what may and may not be said about a result), anchoring, and selective disclosure (publish each entry in full, as a summary, or hidden while the hash chain still proves nothing was dropped): 15 tools in 0.7.0. See the guide and llms.txt.

Honest limits

A local ledger is tamper-evident, not tamper-proof, until its head is published or timestamped outside your control. Results are single-operator unless a card says otherwise. Protocolith does not run experiments or judge whether a protocol is good.
